# Webinar Landing Page — Design Document

## 1. Design Reference
Primary reference:
**Wemeet — Webinar Landing Page**

Reference:
`https://dribbble.com/shots/20958621-Wemeet-Webinar-Landing-Page`

Use the visual language as inspiration, not as a direct copy.

Do not reproduce the exact:
- Copy
- Images
- Illustrations
- Artwork
- Layout
- UI
- Branding

## 2. Design Direction
**Premium SaaS + Modern Webinar + Editorial + Conversion-focused**

Keywords:
- Minimal
- Premium
- Clean
- Friendly
- Modern
- Human
- Spacious
- High-converting

## 3. Core Principles
- Oversized editorial typography
- Generous whitespace
- Human-centered hero imagery
- Rounded cards
- Soft purple accents
- Strong CTA hierarchy
- Subtle motion
- Minimal navigation

## 4. Color System
Primary Purple: `#5B2EFF`
Dark Purple: `#3B1DB8`
Background: `#FAFAF8`
White: `#FFFFFF`
Primary Text: `#111111`
Secondary Text: `#6B6B6B`
Border: `#E8E8E8`

## 5. Typography
Primary: Inter
Alternatives: Manrope, Plus Jakarta Sans, Geist

Scale:
- Hero: 64–80px desktop, 40–48px mobile
- Section: 44–56px
- Card: 20–24px
- Body: 16–18px
- Small: 13–14px

Weights:
- Display: 700–800
- Headings: 600–700
- Body: 400–500

## 6. Layout System
Maximum content width: 1200–1280px
Desktop padding: 32–48px
Tablet: 24–32px
Mobile: 16–20px
Desktop grid: 12 columns

## 7. Navbar
Minimal:
- Logo
- What You'll Learn
- Speaker
- FAQ
- Reserve My Seat

Mobile:
- Logo
- Menu

## 8. Hero
Background: `#FAFAF8`

Desktop:
- 50% content
- 50% visual

Mobile:
- Content
- CTA
- Event details
- Visual

Hero content:
- LIVE ONLINE WEBINAR
- Large outcome-focused headline
- 2–3 lines supporting copy
- Date
- Time
- Live indicator
- CTA
- Trust microcopy

## 9. Hero CTA
**Reserve My Free Seat →**

Style:
- Background: `#5B2EFF`
- Text: white
- Height: 52–56px
- Radius: 14–16px

Hover:
- Small upward movement
- Soft shadow
- Subtle brightness change

## 10. Hero Visual
Use a high-quality speaker/person visual with:
- Abstract purple shape
- Laptop/tablet
- Floating webinar UI

Floating UI examples:
- Live participant card
- Chat card
- Webinar attendee card

Cards:
- White
- Soft shadow
- Rounded
- Minimal borders

## 11. Decorative Graphics
Use subtle:
- Purple blobs
- Circles
- Dots
- Thin lines
- Small stars/sparkles

Decorations must support the hero, not overpower it.

## 12. Trust Section
White background.

Suggested layout:
- Trusted by thousands
- Attendee count
- Session count
- Rating
- Countries

Use real values only.

## 13. Problem Section
Off-white background.

Heading:
**Still Struggling With [The Same Problem]?**

Three cards with large numbers:
- 01
- 02
- 03

Each card contains a problem title and short explanation.

## 14. Learning Section
White background.

Heading:
**Here's Exactly What You'll Learn**

Six cards:
01, 02, 03, 04, 05, 06

Desktop:
3 × 2 grid

Mobile:
Single column

## 15. Learning Cards
- Radius: 20px
- Padding: 28–32px
- White background
- 1px border
- Subtle hover lift
- Purple accent

## 16. Webinar Experience
Two-column editorial section:
- Left: webinar screenshot/visual
- Right: explanation

Content:
01 Expert presentation
02 Live interaction
03 Real examples
04 Q&A

## 17. Speaker Section
Off-white background.

Two-column:
- Left: speaker visual
- Right: speaker details

Show:
- MEET YOUR HOST
- Name
- Designation
- Bio
- Credibility stats

## 18. Speaker Image Treatment
Use:
- Organic purple background
- Portrait
- Floating "EXPERT" badge

Avoid generic rectangular corporate headshots.

## 19. Agenda
White background.

Vertical timeline:
01 Introduction
02 Core Framework
03 Live Demo
04 Strategy
05 Q&A

Use purple numbers and a thin neutral connector line.

## 20. Testimonials
Off-white background.

Three strong testimonial cards.

Each:
- Avatar
- Rating
- Quote
- Name
- Designation

Avoid fake testimonials.

## 21. Registration Section
Strongest conversion section.

Background:
`#5B2EFF → #3B1DB8`

Heading:
**Your Seat Is Waiting.**

Subtext:
**Register free and join us live.**

## 22. Registration Card
White floating card.
Radius: 28px.

Fields:
- Full Name
- Email
- WhatsApp Number

CTA:
**Reserve My Free Seat →**

## 23. Countdown
Place above the registration card.

Display:
- Days
- Hours
- Minutes
- Seconds

Use large numbers and simple labels.

## 24. FAQ
White background.

Accordion:
- Question
- Plus/minus icon
- Smooth expansion

Accessible keyboard interaction is required.

## 25. Final CTA
Off-white background.

Heading:
**Ready to Take the Next Step?**

CTA:
**Reserve My Free Seat →**

## 26. Footer
Minimal:
- Logo
- Privacy
- Terms
- Contact
- Copyright

## 27. Border Radius
- Small: 10px
- Medium: 16px
- Large: 24px
- Hero visual: 28–32px

## 28. Shadows
Use soft, low-opacity shadows.
Avoid heavy elevation.

## 29. Iconography
Use Lucide icons consistently.
Recommended stroke: 1.5–2px.

Avoid mixing icon families.

## 30. Animation
Use Framer Motion for:
- Hero reveal
- Section reveal
- Floating UI
- Card hover
- FAQ transitions
- CTA micro-interactions

Respect `prefers-reduced-motion`.

## 31. Mobile Design
Mobile is a first-class design.

Requirements:
- Single column
- Full-width CTA
- Smaller hero typography
- Simplified visual
- Reduced decoration
- Sticky bottom CTA

## 32. Mobile Sticky CTA
Fixed bottom CTA:
**Reserve My Free Seat →**

Height approximately 60–68px.

Ensure it does not block content.

## 33. Section Rhythm
Hero → Trust → Problem → Learning → Experience → Speaker → Agenda → Testimonials → Registration → FAQ → Final CTA

Alternate off-white and white sections for visual rhythm.

## 34. Design Don'ts
Avoid:
- Excessive gradients
- Too many colors
- Generic stock photos
- Giant paragraphs
- Excessive glassmorphism
- Heavy 3D
- Heavy shadows
- Too many competing CTAs
- Excessive animation
- Fake scarcity
- Fake testimonials

## 35. Design Formula
Wemeet visual language
+
Modern SaaS
+
Premium creator/education aesthetic
+
Conversion-focused webinar funnel

## 36. Final Creative Direction
Create a premium, modern webinar landing page inspired by Wemeet's clean SaaS aesthetic, using oversized editorial typography, a purple-and-neutral color system, human-centered hero imagery, floating webinar UI elements, generous whitespace, rounded cards, subtle motion, and a highly focused registration experience.
